dumps

Every dump from the client, cut for whatever you need it for: something to search, something to paste, something to grep.

build version-4ea8e85481e34f46 dumper 2.2.6 dumped 23:01 13/11/2026

offsets

Values read out of the client, grouped by the class they belong to.

AnimationTrack::Animation = 0xa0

  • offsets the whole table, searchable in the browser
  • offsets.hpp the same values as a C++ header, namespaces and all
  • offsets.cs the same values as a C# class
  • offsets.txt one name and hex value per line, for diffing two dumps

fast flags

Engine flags with their values, searchable by name or category.

AudioFocusService = 0x8295588

  • fflags every flag with its value, grouped by category
  • FFlags.hpp the flags as a C++ header
  • FFlags.cs the flags as a C# class
  • FFlags.txt the flags as plain text

types and structs

What the dumper found in the binary, laid out the way it sits in memory.

AnimationTrack.Looped = 0xcc

  • types types with the fields each one holds
  • Struct.hpp struct layouts straight from the dumper

tools

What you do with a dump after you have two of them.

  • diff two dumps in, the values that moved out, without leaving the tab

Every dump that was kept, so a value that moved can still be looked up in the build it moved from.
