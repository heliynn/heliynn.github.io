index

dumps

Everything the dumper prints, in one place. Each set is a page you can search, plus the same data as a header to paste or a file to grep.

offsets

Values read out of the client, grouped by the class they belong to.

  • offsets.html the whole table, searchable in the browser page
  • Offsets.hpp the same values as a C++ header, namespaces and all hpp
  • Offsets.cs the same values as a C# class cs
  • Offsets.txt one name and hex value per line, for grep and diff txt

fast flags

Engine flags with their values, searchable by name or category.

  • fflags.html every flag with its value, grouped by category page
  • FFlags.hpp the flags as a C++ header hpp
  • FFlags.cs the flags as a C# class cs
  • FFlags.txt the flags as plain text txt

types and structs

What the dumper found in the binary, laid out the way it is laid out in memory.

  • types.html types with the fields they hold page
  • Struct.hpp struct layouts straight from the dumper hpp
