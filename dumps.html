dumps

Everything the dumper pulled out of the client. Search it on a page here, or take the file and grep it yourself.

build version-4ea8e85481e34f46 dumper 2.2.6 dumped 23:01 13/11/2026

offsets

Every value the dumper read, filed under the class it came from.

AnimationTrack::Animation = 0xa0

  • offsets the whole table, filtered as you type
  • offsets.hpp the same values as a C++ header, namespaces included
  • offsets.cs the same values as a C# class
  • offsets.txt one name and one hex value per line, easy to diff

fast flags

Engine flags and what they are set to. Search by name, or by category if you only remember roughly where it lives.

AudioFocusService = 0x8295588

  • fflags every flag and its value, sorted by category
  • FFlags.hpp the flags as a C++ header
  • FFlags.cs the flags as a C# class
  • FFlags.txt the flags as plain text

types and structs

The types the dumper found in the binary, with their fields in the order they sit in memory.

AnimationTrack.Looped = 0xcc

  • types each type and the fields it holds
  • Struct.hpp the layouts as the dumper wrote them

tools

For when you have two dumps and want to know what moved between them.

  • diff two dumps in, the values that moved between them, without leaving the tab

the raw json is here too, if you would rather parse it yourself: offsets.json, FFlags.json, Types.json
